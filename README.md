# vodic.domovina.ai

Neslužbeni vodič, korak po korak, kojim svaki građanin RH dođe do ispravne
Certilia prijave: aplikacija Certilia mobileID na mobitelu + lozinka Certilia
računa + probna prijava koja uspije.

Nastao je jer je prijava Certilijom preduvjet za ulazak u
[e-satnicu](https://e-satnica.domovina.ai), a ljudi zapinju prije nego što
stignu do nje. Vodič je zamišljen za višekratnu upotrebu: svaka aplikacija koja
koristi „Prijava s Certilijom" može poslati korisnike ovamo (`?app=<ime>`) i
dobiti ih natrag spremne za prijavu.

**Nije službena stranica Certilije ni AKD-a.** Svi tekstovi i snimke ekrana su
naši; postojeći Certilia/AKD videi i baza znanja služe samo kao izvor znanja.

Stanje: planiranje i istraživanje. Vidi [`docs/plan.md`](docs/plan.md).
